# HBI architecture and the future-package boundary (Paper-1 code review, 2026-08-26)

**The one-line map.** `GP finder inference → catalogue/posterior products → HBI / selection / response / population inference → paper products.` The finder (`gpy_dla_detection/`, `dlasearch.py`, `run_bayes_select.py`) writes catalogues; nothing downstream imports it (one exception: `tools/h2_inject_archive.py` uses `gpy_dla_detection.inject_absorber.inject_voigt` to build the H2 injection archive). The HBI engine consumes ONLY a pack (`CDDF_analysis/hbi_mcmc/pack.py` schema) — no fitsio/h5py/astropy anywhere in the core — and every DESI-specific step lives in the pack producers.

## 2. The engine's input contract (the pack)
23 required keys (fail-closed loader), 8 optional (three of which — `resp_N_ref`, `resp_N_fit_range`, `fp_eta_c` — are hard requirements of the fold), and the 12-key all-or-none adopted-contract stamp group (v1.2). Axes: observed N̂ bins `c`, true-N basis `b`, fine z `k`, coarse z `K`, SNR strata `s`, completeness cells `m`, response cells `(SR, ZR)`. Five interfaces a producer must satisfy: **completeness** (`molly_n_det/n_tot` raw counts on `molly_nhi_edges`; Jeffreys surface + Farr gate inside the engine), **response operator** (moment polynomials + calibrated covariate range + reference point; clamp mode), **FP block** (`fp_counts`, `fp_ell_eff`, `fp_w_sightline_ratio`, `fp_E_alloc`, `fp_eta_c`, `t_sigma`), **truth counts** (mock closure only; zero sentinel on real data), and **window / collar / thresholds** — which today enter only through the adapters and the `.selection_contract.json` sidecar (the most under-specified interface; see §5). Full key table: `docs/PAPER1_REPRODUCTION.md` companion, and `pack.py:87-190`.

## 3. The engine's output contract
Run JSON (`cc_real_posterior`: `pack`, `pack_provenance`, `guards{G_A_real_mode…}`, `thresholds`, `reporting_bins`, `diagnostics{split_rhat, perchain medians, potential energy…}`, `run_config`); `_fdraws.npz` (`f`, `ntrue_edges`, `zf_edges` [+ `truth_f`, `dX_k` for validation runs; + `draw_index_*` for the pool]); the pooled artifact (`selection`, `draw_index`, `thresholds`, `reporting_bins`, `perz_paper1`, hash blocks). The three `_fdraws` layouts are not yet self-describing (pre-extraction step 6).

## 4. What is DESI-specific inside the engine (to be injected, not hard-wired)
`reporting.py` constants `NONIDENT_EDGE = 19.7`, `RESPONSE_ANCHOR_CEILING = 21.6`, `COMPLETENESS_ADOPTED = "molly172"`, `PAD_FLOOR_ADOPTED = 19.0`, the 2LPT-0 `RESPONSE_ANCHOR_MEASURED`; `model_a.TIERS`; `pack.REAL_*_EDGES` grid defaults and `FP_ETA_BANDS_COMMITTED` naming a run; `perz_gate.CRIT` (B1–B5). These are the Paper-1 *policy*; they belong in a `ReportingPolicy` object the engine receives.

## 5. What blocks packaging today (behaviour-neutral fixes; none applied in this review)
1. `hbi_mcmc/__init__.py` imports jax eagerly → forces two conda envs and 12 file-direct `spec_from_file_location` workarounds (`extract_pack.py:218/338/720`, `reporting.py:905`, `build_scan_packs.py:44`, `extract_pack_real.py:54`, …). Fix: lazy `enable_x64()` in the jax modules; add an import-boundary test (core imports leave `CDDF_analysis.hbi`, `fitsio`, `h5py`, `astropy`, `examples`, `gpy_dla_detection` out of `sys.modules`).
2. Hard-coded roots: `/scratch/...` and `/nfs/turbo/...` module constants in every producer/runner (`extract_pack.py:133,147,176`, `extract_pack_real.py:64-70`, `upgrade_packs_v2.py:33-42`, `hbi/track_c_tf_hz.py:75-81`, `hbi/cddf_catalog_hbi.py:84-88,2485-2492,5217-5224`, …), `/home/mfho/.conda/...` interpreter literals (`run_posterior.py:575`, `run_e4_conditioning.py:74`), a cross-worktree path (`d1_ladder.py:425`), `/tmp` env-var defaults; paper repo `common.py` artifact registry. Fix: one `paths.py` per layer with env-var overrides, byte-identical defaults.
3. Implicit file conventions: seed from the filename regex `_s(\d{8})\.json$` (`cc_pool_posterior._seed_of`; `run_config.seed` now exists), `path[:-5] + "_fdraws.npz"` string surgery at 9 sites, provenance/selection/superseded status as basename sidecars and directory globs, family from a basename substring (`perz_gate._fam`), the all-zero `truth_counts` sentinel meaning "real pack", the adopted-config tag string duplicated in 3 modules. Fix: a `RunArtifact` object; versioned `_fdraws` layouts; seed read from the JSON.
4. Policy inside the engine (§4). Fix: `ReportingPolicy` + a `desi_policy.py` instance; `pack.py` grid presets registry.
5. The selection/window contract absent from the pack itself (only the sidecar). Fix: an additive, validated `selection_contract` key written by `write_selection_contract_sidecar`.
6. Four hybrid CLI modules (`cc_pool_posterior`, `perz_gate`, `certify_g_support`, `cddf_recovery_audit`): split pure kernels (already tested) from thin `main()`s.

## Response / kernel interfaces (part of the future reusable boundary; PI requirement 2026-08-26)
The response chain is a generic *forward-response calibration* module, not a Paper-1 script. Its interfaces, in call order:

| stage | interface (current file:function) | contract |
|---|---|---|
| calibration events | `CDDF_analysis/hbi/cddf_catalog_hbi.py:load_and_cut_catalog(cfg, truth_nhi_floor, …)` | in: detections + truth + BAL/SNR sidecars + completeness matrix; out: op-cut catalogue with `NHI_TRUE`, `NHI_TILT_HOST` (**hierarchical tilt assignment**: primary ≥ matrix-floor match preserved, hostless detections only draw from the low-floor pool), `good_mask`. Changing this contract changes every downstream object (the 2026-08-16 `0ecfeea` lesson). |
| forward response measurement | `znz_kernel.py:measure_forward_response(cat_cut, good_mask, cfg, host_col="NHI_TILT_HOST", lam_rf_min, …)` | in: calibration events; out: per-cell (SNR × z) moment measurements of x̂ given x_true |
| forward response fit | `znz_kernel.py:fit_forward_response(meas, deg_xhat=1, deg_z=2, fit_floor=19.5, …)` → `ForwardResponseModel` | out: `mu/sig/skew_coef`, `fit_rng`, `N_ref`; persisted by `build_forward_cache` (`forward_response_2lpt0.npz`, 15 arrays); loaded by `load_forward_response(path)` |
| fit covariance | `znz_kernel.py:build_forward_response_fit_resample(...)` + `refit_forward_response_from_resample(...)`; driver `hbi_mcmc/build_kernel_fit_ensemble.py --n-draws --seed --frozen-npz --out` | sightline multinomial bootstrap of the *same committed fit*; unit-weight gate = the refit must reproduce the point model it resamples around (fail-loud); out: coefficient ensemble → `resp_fitcov_diag = Var(order-0 mu, sig)` |
| adopted operator | schema `adopted_response/v1.1` (`mu/sig/skew_coef (3,3,4)`, `fit_rng`, `N_ref`, `carrier_* (96,…)`, `carrier_shared3`, `carrier_unit_gate`, `provenance`) — builder: committed routine of record (see `docs/PAPER1_REPRODUCTION.md` §6a after the 2026-08-26 recovery) | per-cell deg-2 skew-normal moment surfaces + one shared cubic; 96-draw carrier with unit-weight gate; consumed only through `count_conserving_fold.phi_from_surfaces` / `cc_fold_adopted` (count-conserving, renormalised, deployed φ_ref) |
| pack stamping | `hbi_mcmc/extract_pack_real.py --stamp-v12 [--adopted PATH] [--kfe PATH]`, `hbi_mcmc/upgrade_packs_v2.py` | writes the `adopted_*` keys + `resp_fitcov_diag` into the pack; verifies the adopted-CC level identity ≤ 1e-6 |

Packaging note: the DESI-specific parts are the calibration-event loader (file layouts, column names) and the hard-coded artifact paths in the two stampers; the measurement/fit/resample/fold functions are already data-agnostic and belong to the generic core.
